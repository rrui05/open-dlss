The native implementation already existed in OpenDLSS. This experiment added a timing entry and input adapters; it did not introduce a new network or new PTX optimizations. Vulkan submits CUDA/PTX kernels and SPIR-V utilities. The PyTorch route is an independent reference with FP32 tensors emulating FP8 publications; it is not a native FP8 tensor-core implementation.

Cross-backend numerical tolerance: FAIL. Native timing is valid as a runtime measurement, but the native output did not pass the WebGPU ±1-code comparison. The independently prepared 16-lane input features were bit-identical. With identical features, the raw heads still differ. RGB PSNR: 50.3643 dB; mean absolute error: 0.4814/255; maximum error: 8/255. The responsible graph operator has not been isolated. Each backend's repeated outputs were finite and repeatable in the recorded checks.
